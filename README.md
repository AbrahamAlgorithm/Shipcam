# Shipcam

A native macOS screen recorder that hands back a finished demo video. Record your screen, with or without your face, then polish it in the same app: zooms, cursor, background, captions and audio.

> **Status:** early development. There is nothing to install yet.

## Planned features

- Record a display, a window or an area, with mic, system audio and an optional webcam.
- Automatic zooms and a smooth, redrawn cursor, all editable on a timeline.
- Styled backgrounds with padding, rounded corners and shadows, in any aspect ratio.
- Trims, speed changes, annotations, blur regions, captions, color grading, and music with ducking.
- Export to MP4 or GIF. Your original recording is never modified.

Shipcam will require macOS 14 or later.
